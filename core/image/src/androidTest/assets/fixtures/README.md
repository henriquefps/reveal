# Synthetic fixtures

`ramps-srgb.png` is generated by a ten-line script (four 256x48 bands: grey, red, green and blue ramps, value = x).
The others are conversions made with macOS `sips`: `ramps-srgb.jpg` (quality 95) and `ramps-srgb.heic` from the PNG,
`ramps-p3.jpg` from the PNG matched to the Display P3 profile (colours converted, ICC profile embedded).
No photograph is involved; the files are public domain (CC0).
